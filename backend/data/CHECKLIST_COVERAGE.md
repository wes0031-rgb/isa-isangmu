## 📌 먼저 — "데이터 수집" 은 4단계입니다

| 단계 | 뜻 | 현재 상태 |
|---|---|---|
| 1. **원천 수집** | 파일이 `backend/data/` 에 있음 | **✅ 108 파일 완료** |
| 2. **청킹** | JSONL 청크로 변환 | **✅ 2,297 청크 완료** (A 법률 1,950 / B 절차 200 / C 유튜브 147) |
| 3. **Azure AI Search 인덱싱** | 청크를 Azure 에 업로드 | **❌ Azure 5종 리소스 발급 대기** |
| 4. **앱 연결** | RAG retrieval 파이프라인 연결 | **❌ 3번 먼저 돼야 함** |

팀원끼리 "수집됐냐 안됐냐" 로 헷갈릴 때 이 표를 먼저 보여주세요. "수집" 한 단어가 4단계를 뭉뚱그려서 다른 얘기를 하게 만듭니다.
