이사이상무 · 전체 브랜딩 제안

로고 컨셉 탐색부터 앱 내부 터치포인트까지 한 페이지에 정리. 팀 논의용 · 오렌지 태그는 최종 선택 · 초록 태그는 코드에 이미 적용됨.

1. 로고 컨셉 탐색 — 5가지 후보

처음 제안한 5개 방향. 앱 아이콘으로서의 단순성·인지도·브랜드 의미 종합 고려 후 #2 집 + 체크 최종 채택.

1. 박스 + 체크

아이소메트릭 이사 박스 + 체크. "짐 포장 완료" 의 직관적 시각화.

⭐ 최종 선택

2. 집 + 체크

집 실루엣 안 큰 체크 마크. "새 집으로 이사 완료" 의미 + 작게 줄여도 또렷.

3. 방패 + 체크

"이상무"의 군대식 확인 의미 + SafeContract 안전 메시지 정합.

4. 이사 여정

체크 마크를 옛집→새집 경로로 변환. 컨셉은 좋으나 작으면 디테일 약함.

5. 한글 워드마크

"이사 / 이상무" 2단 타이포. 스플래시/헤더용 적합, 아이콘 단독은 약함.

2. 최종 프로덕션 아이콘 ✓ 적용 완료

집 + 체크 컨셉을 Expo 앱 아이콘 / 스플래시 / Android Adaptive / Favicon 4종 PNG로 확장. app.json 연결 완료.
