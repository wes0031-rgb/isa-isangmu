## 🎯 한 줄 요약

기존 서비스(HUG·등기소·실거래가·내집스캔)는 **"이 집 위험한가"**까지만. 계약 후 전입신고·공과금·인터넷 이전은 아무도 안 알려줍니다. MoveWise는 그 **빈 칸**을 채웁니다.

## 🏗 핵심 기능 2가지

### 📋 메인: 개인화 이사 체크리스트 (RAG)
사용자 조건 입력 → LLM이 검색 쿼리 생성 → Azure AI Search 하이브리드 검색 → LLM 구조화 → D-day 타임라인. 각 항목에 법 조항 citation.

### 🛡 부가: SafeContract (등기부등본 해석기)
등기부 텍스트 / PDF → Document Intelligence OCR → LLM Structured Output → Python 계산 → 법률 RAG → 쉬운 말 해석 + 기존 서비스 안내.
