# 📎 노션 업로드 가이드

이 폴더의 파일들을 노션 워크스페이스에 올리는 방법.

---

## 🅰 방법 1: 한 번에 일괄 업로드 (권장)

1. 노션 사이드바에서 올릴 상위 페이지 선택
2. 우측 상단 **⋯** 메뉴 → **Import** (또는 **가져오기**)
3. **Markdown & CSV** 선택
4. 이 `notion_share` 폴더 통째로 드래그 or 선택
5. 자동으로 10개 파일이 각각 노션 페이지로 변환됨

> ⚠️ 노션 Markdown Import는 번호 접두사(`01_`, `02_` ...)를 그대로 파일명으로 가져옵니다. 가져온 후 정렬하려면 사이드바에서 수동 drag 정렬하거나 접두사 그대로 두면 알파벳 순 자동 정렬.

---

## 🅱 방법 2: 한 파일씩 드래그

노션 페이지에서 빈 줄 클릭 → `/import` 또는 파일을 직접 드래그 앤 드롭.

---

## 🅲 방법 3: 직접 붙여넣기

각 `.md` 파일을 텍스트 에디터로 열어 내용 복사 → 노션 페이지에 붙여넣기.
노션이 자동으로 마크다운 문법을 인식합니다.

## 🖼 이미지 처리

`movewise_architecture.png` 는 `00_노션_인덱스.md` 와 `03_시스템_아키텍처.md` 에서 참조됩니다.
노션이 폴더를 통째로 import하면 이미지도 함께 업로드되어 자동으로 표시됩니다.

만약 이미지가 깨지면 수동으로 `.png` 파일을 해당 페이지에 드래그하세요.

## ✅ 업로드 후 추천 구조

노션 워크스페이스에서 이렇게 정리하면 팀이 쉽게 찾을 수 있어요:

```

├── 🏠 00_노션_인덱스               ← 랜딩 페이지 (맨 위)
├── 📋 01_프로젝트_README
```
