# 09. 실행 가이드

팀원이 로컬에서 MoveWise를 실행하거나, 공유 링크를 받아 테스트하기 위한 최소 가이드.

---

## ⚡ 빠른 시작 (공유 링크만 보기)

이미 가동 중인 공유 링크 접속:

- **앱**: `https://plots-discovered-monte-produces.trycloudflare.com`
- **API**: `https://habitat-surrounded-websites-accessible.trycloudflare.com`

> ⚠️ Cloudflare Quick Tunnel은 Mac이 켜져 있는 동안만 유효합니다.

Cloudflare 경고 페이지가 뜨면 **"Continue"** 클릭. 모바일 브라우저(iOS Safari, Android Chrome)도 지원.

---

## 🛠 로컬 개발 세팅

### 1. 사전 요구사항

```bash
python3 --version   # 3.11+
node --version      # 20+
npm --version       # 10+
```

### 2. `.env` 설정

`.env.team` 파일을 받아 `.env`로 복사 후 Azure 키 본인 값 입력.

```bash
cp .env.team .env
```

```bash
# 이미 발급된 키 (공유)
DATA_GO_KR_SERVICE_KEY=<공공데이터포털 마스터키>
JUSO_API_KEY=<도로명주소 API 키>

# ⏳ 발급 필요
LAW_OC=                       # open.law.go.kr 마이페이지 → OC 확인
AZURE_OPENAI_ENDPOINT=
AZURE_OPENAI_API_KEY=
AZURE_OPENAI_DEPLOYMENT_NAME=gpt-4o
AZURE_OPENAI_API_VERSION=2024-10-21
AZURE_OPENAI_EMBED_DEPLOYMENT=text-embedding-3-small

AZURE_SEARCH_ENDPOINT=
AZURE_SEARCH_API_KEY=
AZURE_SEARCH_LAW_INDEX=moving-law-index
AZURE_SEARCH_PROCEDURE_INDEX=moving-procedure-index

AZURE_DOCINTEL_ENDPOINT=
AZURE_DOCINTEL_API_KEY=

AZURE_BLOB_CONNECTION_STRING=
AZURE_BLOB_CONTAINER_NAME=moving-guide-docs
```

> **Azure 키가 없어도 백엔드는 rule-based + 로컬 검색 폴백 모드로 동작합니다.**

### 3. Python 의존성

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 4. Node 의존성

```bash
cd frontend/movewise-app
npm install
```

## 🚀 실행

### 백엔드 (FastAPI)

```bash
cd 2차프로젝트
python3 -m uvicorn backend.app.main:app --reload --host 127.0.0.1 --port 8765
```

접속 확인:
- http://127.0.0.1:8765/
- http://127.0.0.1:8765/docs (Swagger UI)

### 프론트엔드 (Expo 앱)

**웹 브라우저** (가장 빠른 확인)

```bash
cd frontend/movewise-app
npx expo start --web
```
→ http://localhost:8081 자동 열림

**iOS 시뮬레이터** (Xcode 필요)

```bash
npx expo start --ios
```

**Android 에뮬레이터** (Android Studio 필요)

```bash
npx expo start --android
```

**실제 폰** (Expo Go 앱 설치 후 QR 스캔)

```bash
npx expo start
```

### Streamlit 데모 (선택)

파이썬 빠른 데모가 필요하면:

```bash
cd 2차프로젝트
streamlit run frontend/streamlit_app.py
```
→ http://localhost:8501

## 🌐 팀 공유 (Cloudflare Quick Tunnel)

### 1. 백엔드 터널

```bash
cloudflared tunnel --url http://127.0.0.1:8765
```

출력된 URL 복사: `https://<random>.trycloudflare.com`

### 2. 프론트엔드 재기동 (백엔드 URL 주입)

```bash
cd frontend/movewise-app
EXPO_PUBLIC_API_URL="https://<backend-tunnel>.trycloudflare.com" \
  npx expo start --web --port 19006
```

### 3. 프론트엔드 터널

```bash
cloudflared tunnel --url http://127.0.0.1:19006
```

→ 출력된 URL이 팀원 공유용.

### cloudflared 미설치 시

```bash
brew install cloudflared
```

## 📥 데이터 수집 (옵션)

이미 수집된 데이터는 `backend/data/`에 있습니다. 재수집이 필요하면:

```bash
# 순서대로 실행
python3 backend/scripts/ingest_easylaw.py         # 이사 카테고리 22건
python3 backend/scripts/ingest_easylaw_lease.py   # 주택임대차 31건
python3 backend/scripts/ingest_citygas.py         # 도시가스 매핑
python3 backend/scripts/ingest_holidays.py        # 공휴일 22건

# 청킹 + 큐레이션
python3 backend/scripts/chunk_easylaw.py          # 53 → 361 청크
python3 backend/scripts/curate_chunks.py          # 361 → 200 청크

# 품질 평가
python3 backend/scripts/evaluate_checklist.py     # 20 쿼리 자동 평가

# LAW_OC 발급 후
python3 backend/scripts/ingest_laws.py            # 법률 원문 8종

# Azure 발급 후
python3 backend/scripts/upload_to_search.py --create-indexes
```

## 🐛 트러블슈팅

### `ModuleNotFoundError: No module named 'pydantic_settings'`
```bash
pip install pydantic-settings
```

### `pip install` 실패 — "externally-managed-environment"
```bash
# 가상환경 사용 또는
pip install --break-system-packages --user <패키지>
```

### Expo 웹이 흰 화면
- 브라우저 콘솔에서 CORS 에러 확인
- 백엔드가 돌고 있는지 `curl http://127.0.0.1:8765/` 확인
- `EXPO_PUBLIC_API_URL` 환경 변수 확인 후 재기동

### 포트 충돌
```bash
# 사용 중인 프로세스 찾기
lsof -i :8765
lsof -i :19006

# 종료
kill <PID>
```

### 공휴일 API 401
- `DATA_GO_KR_SERVICE_KEY` 값 확인
- data.go.kr에서 "법제처 찾기쉬운 생활법령정보" 승인 여부 확인
